# Contributing to TrueFlow-Analyzer

First off, thank you for considering contributing to TrueFlow-Analyzer! It's people like you that make TrueFlow-Analyzer such a great tool for network analysis and telemetry.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our [Issues](../../issues) to see if someone has already opened an issue for it. If not, please open a new issue!

## Setting up your environment

1. Fork the repo and create your branch from `main`.
2. Ensure you have Python 3.10+ and Node.js 18+ installed.
3. Install the Python dependencies using `pip install -r requirements.txt` (or manually install scapy, scikit-learn, pandas).
4. Run `npm install` in both the `dashboard` and `dashboard-server` directories.

## Pull Request Process

1. Ensure any install or build dependencies are removed before the end of the layer when doing a build.
2. Update the README.md with details of changes to the interface, if applicable.
3. Your PR will be merged once you have the sign-off of the maintainers.

## Code Style

- **Python**: Please adhere to PEP-8.
- **JavaScript/React**: Use ESLint as configured in the `dashboard` directory.

We appreciate your contributions to making DPI and telemetry smarter!
